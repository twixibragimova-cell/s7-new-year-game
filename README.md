# S7 Run — Telegram Mini App prototype

## Что внутри
- `index.html` — автономный игровой прототип на Canvas, без сборки и npm.
- Вертикальный адаптивный экран, свайпы и клавиатурное управление.
- Три полосы, прыжок, подкат, сбор талонов, препятствия, таймер, пауза и финальный экран.
- Подключён Telegram Web Apps SDK; при открытии внутри Telegram вызывает `ready()` и `expand()`.

## Как запустить
1. Разместите `index.html` на HTTPS-хостинге (например, GitHub Pages, Netlify или своём сервере).
2. В настройках бота через BotFather задайте URL Mini App.
3. Откройте приложение из кнопки бота в Telegram.

Для локальной проверки откройте `index.html` в современном браузере.

## Важно
Это рабочий игровой прототип с рисованной Canvas-графикой, а не финальная 3D-игра уровня Subway Surfers. Для production-версии можно заменить нарисованные объекты на 3D/спрайтовые ассеты, подключить таблицу рекордов и серверную проверку результатов.
